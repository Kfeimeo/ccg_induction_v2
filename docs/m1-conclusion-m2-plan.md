## 1. M1 裁定

**M1 的原判据错了，不是实现错了。** 实测数据（`sees` 在单句下有 14 个合法 σ，跨四句取交集仍不收敛）是 CCG 单句方程解集的真实形状，不是 bug。

采纳"选项 1"：**M1 只保证方程本身正确，唯一性整体推迟。**

### 1.1 新的 M1 完成判据

五条，全部必须为绿：

| # | 判据 | 说明 |
|---|---|---|
| M1-a | 金标准 σ ∈ D | 解集完备性的必要条件 |
| M1-b | D 在给定复杂度界下完备且可复现 | 同一输入两次运行 D 完全相同，含顺序 |
| M1-c | 固定词典时 σ 折叠正确 | `the cat sees the dog` → 1 条 σ、2 棵树 |
| M1-d | 剪枝后性能有界 | 6 个自由未知数的句子 < 5 秒 |
| M1-e | **单调性**：`D(C ∪ {s})` 限制到共享变量后 ⊆ `D(C)` | 新增，见下 |

M1-e 是把原文件 §5.1 的命题变成可执行断言。M1 阶段做它成本极低（只有 backbone 式传播，必然成立），而 M3 一旦开始贪心选推导，它就是唯一能捕获"错误合并未被撤销"的测试。**现在不建，M3 出 bug 时无从定位。**

### 1.2 测试改写要求

那五条唯一性测试**不要**标 `xfail`。`xfail` 丢掉了你们已经获得的信息：你们知道的不是"会失败"，而是"恰好哪些解存活"。改成断言精确集合：

```python
def test_minimal_sigmas():
    assert minimal("the")    == {"NP/N"}
    assert minimal("cat")    == {"N"}
    assert minimal("sleeps") == {"S[dcl]\\NP"}
    # 已知对称：主宾方向在无 VP 证据的语料下不可识别，见 §2
    assert minimal("sees")   == {"(S[dcl]\\NP)/NP", "(S[dcl]/NP)\\NP"}
```

同时把 `(14, 29)`、`(2, 2)` 这类原始计数存成 golden values。它们是原文件末尾"每开一条新规则必须记录 backbone 变化"那个指标的基线，M4 开 `>B` 时要对比。

## 2. 新增 §5.4 — 解的对称性与不可识别性

**这不是过度泛化（§5.2），归类要分开。**

`sees` 剩下的两个最小解之间存在一个**自同构**：保持 `the`、`cat`、`dog`、`sleeps` 不动，只翻转及物动词的论元顺序，`(S[dcl]\NP)/NP ↔ (S[dcl]/NP)\NP`。两个词典生成的字符串集**完全相同**（弱等价），只是推导结构不同。§5.2 说的是"语言太宽"，这里两个语言一样宽。

### 2.1 推论：标量目标函数不可能破这个对称

复杂度、斜杠数、arity、depth、MDL、Kanazawa 最小语言判据、狄利克雷过程——全部在这个自同构下取值相同，因此**全部无效**。不要试图通过调权重、加惩罚项来解决，这不是调参问题。

破对称只有两条路：注入不对称的先验（人为约定），或引入打破对称的数据。

### 2.2 正确的解法：VP 证据

关键观察：`(S[dcl]\NP)/NP` 使 `sees the dog` 成为一个 `S[dcl]\NP` 成分，与 `sleeps` 的范畴**相同**；`(S[dcl]/NP)\NP` 下不存在这个成分。因此任何依赖 VP 成分的语言现象都会立刻破坏对称：

- VP 修饰语：`the cat sees the dog quickly`，`quickly = (S\NP)\(S\NP)`
- VP 并列：`the cat sleeps and sees the dog`
- 助动词：`the cat will see the dog`

这三类在当前语料过滤规则下全部被排除，**所以这个歧义是语料过滤的产物，不是 CCG 的固有缺陷。**

### 2.3 要求的动作

在 M1 玩具词典中加入一个副词及至少一句含它的句子，并新增一条测试：

```python
def test_vp_modifier_breaks_symmetry():
    # 加入 "the cat sees the dog quickly" 后
    assert minimal("sees") == {"(S[dcl]\\NP)/NP"}
```

**这条测试的意义超出它本身**：它演示了消歧力量来自**范畴在不同词之间的重用**（`sleeps` 和 `sees the dog` 共享 `S[dcl]\NP`），而不是任何逐词的复杂度指标。这个认识直接约束 §4.5 的设计，见下。

### 2.4 若坚持不加数据

唯一站得住脚的先验不是"斜杠方向偏好"，而是**论元按 obliqueness 排序、主语最后合并**。在 V 居中语言里它强制得出 `(S\NP)/NP`。若采用，必须在文档和代码注释里明确标为**注入的语言学约定**，不是求解结果。默认不采用。

## 3. 修订 §4.5 — 目标函数

原文第一项 `α · |词典条目数|` 不够。改为：

```
cost = α₁ · |词典条目数|
     + α₂ · |词典中出现的不同范畴数|        ← 新增
     + β  · Σ 范畴复杂度
     + γ  · Σ_句子 log(去重后 σ 数)
```

`α₂` 项奖励**范畴在词之间的重用**。这是 §2.3 揭示的真正消歧机制：一个让 `sleeps` 和 `sees the dog` 落入同一范畴的词典，比一个让它们分属两个范畴的词典更好，即使两者的条目数和复杂度总和相同。

### 3.1 必须写明的一条

"如果一句话能用更少斜杠的范畴解释就优先它"是**全局项**，不是逐词规则。它正是把 `sees` 的解从 14 压到 2 的那一项。但若实现成逐词贪心偏好，每个词都会想当原子范畴，结果没有任何句子可推导。实现者极易把这句话读成局部规则，代码里要有注释挡住。

## 4. 新增 §4.6 — 复杂度上的迭代加深

把原文固定的 `arity ≤ 4 / depth ≤ 3` 上限改造成递增变量，作为求解的外循环：

```
for L in 0, 1, 2, 3, ...:
    求解，约束：所有词的范畴复杂度 ≤ L
    若有解则返回
```

这**不是启发式**，是完备搜索的一种顺序，不损失精确性。它自动实现了"种子词"直觉：

- `L = 0`：只有原子范畴，`cat`、`dog` 被迫先定下来
- `L = 1`：引入 `NP/N`，限定词定下来
- `L = 2`：及物动词才进入解空间

种子词自然浮现，不需要人工指定，也不需要处理"从种子向外扩散时遇到分支"的问题。

副产品：**最小可行的 L 是这部语料的一个复杂度下界**，作为报告指标输出。

实现成本接近零——复用现有的剪枝谓词，只把常数换成循环变量。

## 5. M2 工作定义

M2 的目标不变（跨句传播 + 优先队列消元），但根据 M1 的发现，验收判据要改。

### 5.1 不再承诺的事

原文 M2 判据"30 句玩具语料，无需任何决策即可解出"**撤销**。M1 已经证明单句解集远非唯一，跨句交集也不收敛到单点。M2 不可能达到唯一解。

### 5.2 M2 的真实目标

M2 要证明的是**backbone 传播确实有力量**，而不是它能独自解出词典。

| # | 判据 |
|---|---|
| M2-a | backbone 提取正确：所有存活推导 `trail[mark:]` 的交集，限制到词型变量 |
| M2-b | 传播有连锁效应：至少出现一次"A 句的 backbone 使 B 句变成单位子句" |
| M2-c | 优先队列顺序可复现，且短句确实先出队 |
| M2-d | **压缩率报告**：30 句语料处理后，Σ log\|D_s\| 相比逐句独立求解下降的幅度 |
| M2-e | 单调性（M1-e）在跨句传播下仍成立 |

M2-d 是这一阶段唯一真正重要的数字。**如果压缩率很低（比如 < 30%），说明 backbone 传播对这个问题没用**，整个 §4.1 第三种情况的设计需要重新评估，而不是继续往 M3 走。这个判断必须在 M2 做出，不能推迟。

### 5.3 M2 的语料

在 M1 玩具词典基础上扩到 ~30 句，要求：

- 必须含至少一个 VP 修饰语（§2.3）
- 必须含至少一组最小对（两句只差一个词），用来验证最小对通道
- 仍然只用 `>` `<`，无并列、无助动词、无问句，长度 ≤ 8
- 保留完整的金标准词典，每一步都可对照

### 5.4 不要在 M2 做的事

- 不实现拆词（k 值放宽）——M2 语料保证刚性可解
- 不实现决策与回溯——那是 M3
- 不引入 `>B`、类型提升、特征——那是 M4
- 不做性能优化和共享图表——那是 M5

## 6. 备选项归档

以下想法已评估，暂不实施，记录理由备查：

| 想法 | 定位 | 不现在做的理由 |
|---|---|---|
| 狄利克雷过程 | 词典规模的软先验，可替代硬性 k 值假设 | 有价值但解决的是别的问题；对 §2 的对称性无效。M5 之后评估 |
| Lambek 证明网 | 推导的唯一正规形，虚假歧义在构造上不存在 | 需要换掉整个推导表示；且 Lambek 只生成上下文无关语言。M5 若虚假歧义成为瓶颈再评估 |
| Geach 规则 | — | 否决。`Z` 无界，终止性比类型提升更差，且可由 `>B` 导出 |
| Eisner 正规形 | 性能优化（提前剪枝），非语义选择 | M5。验收方式：开与关时**去重后**的 σ 数必须完全相同 |
| obliqueness 先验 | 注入的语言学约定，可破 §2 对称 | 默认不采用；采用则必须显式标注 |

## 7. 给实现者的一句话

M1 的结果是这个项目到目前为止最有价值的一个发现，因为它把"唯一性从哪里来"这个问题从假设变成了实证：**不来自单句方程，不来自跨句交集，不来自任何标量复杂度指标，而来自范畴在不同词之间的重用。** 后续每一个设计决定都要放到这句话下面检验。

继续保持"发现假设被证伪就立刻报告、不靠加机制硬撑"的做法。
