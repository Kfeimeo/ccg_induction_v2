# CCG 词典求解器 — 增补 3：域过滤与不动点

接 `CLAUDE.md` 与 `docs/m1-conclusion-m2-plan.md`。只改三处，其余不变。（修订已同步进 CLAUDE.md §3.2、§4.1、§4.2、§2 表 M2 行、§7.2。）

## 问题

当前全局状态只携带等式（并查集合并），句子只通过 backbone 向外传播信息。这意味着：只有变量被逼成单值时信息才出得去。A 句把 `x_sees` 限制到 14 个候选、B 句限制到 5 个、交集剩 2 个——这个约束完全传不出去，因为它不是等式。

用 CSP 的话说：现在实现的是单位传播，缺的是域过滤（arc consistency）。M1 的数据正好落在两者之间。

`D_s` 先逐句算出来没错，错的是把它当成一趟而不是迭代到不动点。

## 改动

1. **全局状态加域表。** `domain: Var → Set[Cat]`，初值为复杂度界 L 下的全体候选。并查集合并时两域取交集；域变空即冲突（比合一失败更早的检测点）。
2. **局部求解器返回值加一项。** `(D, backbone)` → `(D, backbone, projected_domains)`，后者是把 `D` 投影到本句涉及的每个词型变量。全局侧做交集并记录是否收缩。
3. **重入队条件放宽。** 从"共享变量被合并"改为"共享变量的域发生收缩"。这一条把单遍扫描变成不动点迭代，是整个改动的关键。

精度层级

```
backbone（等式交集） ⊂ 域过滤（逐变量域交集） ⊂ 联合解集
```

域过滤会丢掉变量间的相关性（某句里 `x_sees = c3` 强制 `x_the = d1`，投影后相关性消失）。折中：对 `|D_s| < 50` 的句子额外保留完整 σ 集做 join，超阈值降级为投影。

## 与迭代加深的协同

域过滤怕域太大，而 §4.6 的迭代加深恰好治这个：L=1 时候选只有个位数，L=2 也不过几十个，域可显式枚举。两个机制配套使用。

## M2 判据修订

M2-d 拆成两个数分开报：

* 等式传播贡献：只开 backbone 时 `Σ log|D_s|` 的下降
* 域过滤增量贡献：再开域过滤后的额外下降

比值决定域过滤值不值得。预期域过滤显著更大；若不是，问题在语料多样性而非算法。

M2 语料要求追加一条：同一个动词必须出现在结构不同的宾语上下文里（`the dog` / `dogs` / `the big dog`）。M1 那部语料每个宾语都是 `the N`，是同一上下文的四次重复，域交集当然不收缩——"跨句也救不了"那个结论是语料造成的，不要当成原理。

注意区分：§5.4 的对称性是原理上不可破；域不收缩只是数据没提供区分。两者不要混。
