# CCG 词典求解器 — 增补 4：纯论元退化引理

接前三份文件。本文件解释 M2 实测的 0% 压缩率，并据此修正 §4.1、§4.2、§4.6 与语料约束。增补 3 的域过滤机制不撤销，但适用条件被大幅收窄。（修订已同步进 CLAUDE.md。）

## 1. 引理

**纯论元退化引理。** 只开 `>` `<` 时，对句子 $s = w_1 \dots w_n$ 的任意位置 $k$，构造 $C_k$ = 按邻接顺序逐个吃掉其余 $n-1$ 个词的链式函子（吃左用 `\`、吃右用 `/`，交错顺序任选）。其 arity $= n-1$，depth $= 0$，复杂度 $= n-1$。

若 $n - 1 \le L$，则存在 $\sigma_k \in D_s$，其中除 $w_k$ 外所有词都绑定到互不相同的自由变量。

推论

1. 任一词型变量在 $D_s$ 上的投影含自由变量，极小化后为全体 → 逐变量域过滤恒为零。
2. 由于 $k$ 任取，任意真子集都可同时自由 → 对任意真子集的关系投影同样不受约束。
3. 任何基于投影的过滤要生效，必要条件是 $L < n - 1$，即 $n \ge L + 2$。

与实测的对应：M2 实测 L=3、句长 ≤ 8 但多数句子短，30 句 20 词型，压缩率 0.0%、单位子句事件 0、域收缩 20 次但集合仍是全体。这正是推论 1 的预测值。求解器没有错，不动点确实达到，金标准从未被排除，单调性成立——零是正确答案。

实现者观察到的 `john sleeps .` 的两条 σ（`{john=?1, sleeps=S\?1}` 与 `{john=S/?1, sleeps=?1}`）是 $n=2$、$k=1,2$ 两个实例。

推论 2 的实践意义：**这与语料多样性无关。** `sees the dog` / `sees dogs` / `sees the big dog` 三种宾语结构齐备，`sees` 的极小化域仍是全体。增补 3 中"域不收缩可能是语料重复所致"的判断在此不成立，该处措辞作废。

## 2. 对增补 3 的修正

增补 3 说"域过滤会丢掉变量间的相关性"。准确表述是：在 CCG 的退化区内这不是折损，是全损，且推论 2 表明关系投影同样无效。

增补 3 的三处改动（域表、投影、域收缩触发重入队）保留，因为它们在 $n \ge L+2$ 的句子上仍然有效——L=1 的实测（78 个 ground 候选时传播制造了冲突）证明机制本身是工作的。但适用范围从"所有句子"收窄为"非退化句子"。

## 3. 裁定：句对 join 有条件采纳

采纳增补 3 的 join 方案（对 $|D_s| < 50$ 的句子保留完整 σ 集，共享变量时做元组级 mgu 关系交），但只对满足 $n \ge L + 2$ 的句子做。退化句子上 join 由推论 2 保证为零，实现了也是白写。

前置诊断（先做）：统计当前 30 句语料中 $n \ge L + 2$ 的句子数，及这些句子两两共享词型变量的对数。**若非退化句不足 5 句，先补语料再实现 join。** 不要在退化语料上测 join 然后得出"join 也没用"的第三个假结论。

> 诊断结果（2026-09-19，L=3）：非退化句 12/30（句长 5:8 句、6:3 句、7:1 句），两两共享词型 63/66 对。语料不用补。
> 实现备注：非退化句在 L=3 下 |D| 为 127（5 词）、720（6 词）、3990（7 词），增补 3 的阈值 50 一句都覆盖不到，join 阈值改为参数 `join_threshold`，实测用 200。

## 4. §4.1 的前提被证伪

原文 §4.1 称"第三种情况（backbone 传播）是整个系统的性能关键"。这个前提现在被证伪了，且是真正的证伪而非测量误差。

这是第二次出现同一信号。第一次是 M1：把 `sees` 的解从 14 压到 2 的是复杂度项，不是跨句交集。结论是：**信息不在一致性里，在目标函数里。**

M3 的重组：M3 不再是"传播为主、决策为辅"，改为以目标函数为主的分支定界：

* 外循环：L-迭代加深（§4.6，见下）
* 主体：按目标函数代价的分支定界搜索
* 传播：降级为便宜的机会性检查——在非退化句子上跑，在退化句子上跳过

不要在传播层继续投入。它的角色从"主力"变为"剪枝的一个来源"。

## 5. §4.2 修正：优先队列方向反了

原文按 `(未知变量数, 存活推导数, 句长)` 升序，效果是短句优先。对过滤而言这恰好是最坏顺序：短句最退化。改为：

* $n - 1 > L$ 的句子（非退化）优先，其中按 $n$ 降序
* $n - 1 \le L$ 的句子排在其后，它们不能提供任何过滤

注意不要推翻早先的语料建议。早先说"短句信息密度高、方程数/未知数比好"，讲的是语料层面的可解性；这里讲的是单句能否提供过滤。两个指标不同，不矛盾。理想语料是词型少、句子多、但句长略超过 L+1。

## 6. §4.6 修正：停止条件是错的

原文"若有解则返回"会返回错解。实测：最小可行 L = 2，但金标准需要 L = 3（副词 arity 2 + depth 1）。改为：

```
best = None
for L in 0, 1, 2, ...:
    sol = 求解(复杂度界 L)
    if sol and (best is None or cost(sol) < cost(best)):
        best = sol; stall = 0
    elif sol:
        stall += 1
        if stall >= 2: break
return best
```

最小可行 L 只作为下界报告指标，不作为停止条件，也不可当作金标准复杂度的估计。

## 7. 语料约束修正

原"长度 ≤ 8"配 L=3 会让大量句子落入退化区。新增：

* $n \ge L + 2$ 的句子至少占三分之一
* 上限保持 ≤ 8（性能考虑）
* 增补 3 的宾语结构多样性要求保留（它服务于目标函数的范畴重用项，不服务于域过滤）

## 8. 两处实现偏离的裁定

域用模式集合而非显式枚举 —— **确认为永久设计，不是偏离。** L=2 在 4 斜杠内截断已有 136,512 个候选，显式枚举不可行。`None` 表示全体、交集 = 两两 mgu + 按包含关系极小化，语义与增补 3 一致。

弱引用 hash-cons 撤回 —— 同意。强引用表两次语料运行 247 MB，当前规模不构成问题，记入 M5。

## 9. 记入 §5 的新条目

**§5.5 退化推导。** 在仅有应用规则的 CCG 中，"某个词是整句的函子、其余全是纯论元"永远是一条合法推导。它使复杂度界 $L \ge n-1$ 的句子对任何基于投影的约束传播完全透明。这是 CCG 词典求解区别于一般 CSP 的结构性特征：约束的强度取决于 $L$ 与句长的相对关系，而非语料规模或多样性。

副作用：这也解释了为何目标函数必须承担主要消歧责任——退化解在复杂度上极其昂贵（arity $n-1$），只有代价函数能排除它们，一致性检查不能。
